Getting started

Activate your licence

Use the customer activation code or licence file sent to you. Keep it private.

Download installation and activation PDF

Activate Studio

  1. Open Licence → Activate

    Open Trinetra Studio and find Licence in its navigation. Review the agreement and complete the acceptance details if you agree.

  2. Choose your activation method

    Code: paste the complete customer code into the License code field, then select Activate code.

    File: select Import or replace licence and choose the customer .tri-license file supplied to you.

  3. Connect if your licence is managed online

    The app claims an available device seat and receives a signed offline lease. Keep an internet connection available for this step. Subsequent offline use is allowed within the licence and lease terms shown in the app.

  4. Check the details displayed

    Confirm your institution, expiry and offline-until date. If a Computer ID is requested, copy it from this installation and send that ID to your provider.

A Windows device-bound licence does not automatically activate a Mac. A managed multi-seat licence uses the seats allocated by your provider. Ask your provider to transfer or release a seat when changing computers.

One computer per institutional licence

Your provider assigns a licence to a named user and work email within an institution. Requester enables Requests and Review; Segmentation / Studio includes the full suite; Demo & Learning enables the education module. Each new institutional licence activates one computer. Contact your provider to move to another device. Older signed licences retain their existing terms.

If activation does not work

The code is rejected

Copy the complete code without adding punctuation. Use a customer activation code or customer licence file, not an owner credential or private signing key. Contact your provider if the institution or expiry is wrong.

No seat is available

Your provider needs to check the licensed device count and release or move a seat where appropriate. Reinstalling repeatedly will not increase the licensed seat count.

The activation service cannot be reached

Check your connection and your organisation's network restrictions. Ask your provider about the licence's offline allowance. Do not disable hospital security controls.

I only use Trinetra Requests

Requests 0.2 requires a Requester or full-suite Trinetra licence. Use its activation screen at first launch. Studio and Requests can use the same full-suite licence on the same computer. A Requester licence does not enable Studio authoring. The personal profile password protects local request history separately. Older Requests 0.1 builds may not show activation.

When requesting support, include the version and exact error. Keep patient data, activation codes and licence secrets out of public feedback forms.
