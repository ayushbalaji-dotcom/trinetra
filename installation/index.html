Getting started

Install Trinetra

Choose Windows or an Apple silicon Mac. Studio and Requests are separate applications.

WindowsMacDownload the PDF guide
Get your installer from Trinetra. Use the installer supplied to you or your approved download link. This public page provides instructions only; it does not distribute installers, licence keys or owner tools.

Windows

  1. Save and close your case windows

    Save your work, then close Trinetra windows. The v45 Studio setup automatically stops background processes from the installation it is updating. It leaves an open application window alone so your work is protected.

  2. Open the supplied Setup.exe

    Use the Windows installer, for example Trinetra-Version-Alpha-0.3.7-Setup-UNSIGNED-TEST-v45.exe. Follow the on-screen steps.

    Standard Studio setup installs for your Windows account and normally does not need administrator rights. Optional components or your hospital's settings may ask for them. Check the app and source before approving a prompt.

  3. Open Trinetra Studio

    Use its Start-menu shortcut. Read the agreement and complete the acceptance details if you agree.

  4. Activate your customer licence

    Open Licence → Activate and use the code or customer licence file supplied to you. Follow the activation guide.

Setup says the app is running

Save and close any visible Trinetra windows, then select Retry. If an older installer is open, close it and use v45 or later. The new installer checks the lock before removing files and automatically waits briefly for Windows to release them.

Windows or hospital security blocks the installer

This alpha installer is unsigned. Confirm the download with your provider and use your organisation's approved installation process. Do not disable antivirus or hospital security controls.

Apple silicon Mac

Use the Mac installer on an M-series Mac. The Windows EXE cannot be opened on macOS.

  1. Open the supplied DMG and read its instructions

    Use the Studio DMG for the full suite, or the Requests DMG for the clinician request dashboard and Review viewer. Quit the old app before replacing it.

  2. Use the matching installation command, if supplied

    For Studio, the supplied file is Install Trinetra.command. For Requests, it is Install Trinetra Requests.command.

    Keep the command beside its corresponding .app. If supplied separately from the DMG, copy both the matching app and command into the same local folder first. Double-click the matching command and read the Terminal messages.

  3. Enter your Mac administrator password when asked

    The command requests permission to install in Applications. Password characters do not appear while typing; type the password and press Return. Enter it only into the Mac's local prompt. Do not send it to Trinetra or anyone else.

  4. Open the installed app

    Open Studio or Requests from Applications after the command reports success. Activate Studio using its customer licence. Requests does not require a Studio authoring licence.

Signing and the command helper: these Mac alpha apps are locally ad-hoc signed, not Developer ID signed or notarised. The supplied commands verify the app's local signature and remove its quarantine flag after installation. That changes a macOS security flag; it is not notarisation or proof of safety. Review the command and follow hospital IT policy before running it.
No command file was supplied

Follow the DMG's Applications shortcut to copy the app to Applications. If macOS blocks it, contact your provider or IT team for the approved route. Do not assume a command mentioned here is included inside every older DMG.

The command cannot find the app

Keep exactly one matching .app in the same folder as its command. The Studio command needs Trinetra Studio.app; the Requests command needs Trinetra Requests.app. The command cannot find an app stored in a separate subfolder.

The first opening seems slow

Wait for the first screen. One native Studio test took about 137 seconds on first launch and 12 seconds on a repeat. These are observations, not guaranteed timings. If no screen appears, report the app version and exact behaviour without patient information.

The optional WSL solver setup is Windows-only. Choose Not now on Mac. Native Mac patient-specific solver setup is not included in this release.

Set up Requests for a colleague

Install the separate Trinetra Requests application if you need requests and Review without Studio authoring. Create a personal profile, enter your work email and choose a password of at least eight characters. Keep it safely; this pilot has no central password recovery.

In Colleagues, exchange invitations through an approved route and verify the displayed identity. Direct delivery needs permitted network access and both PCs awake. Use the encrypted offline package when direct delivery is unavailable.
