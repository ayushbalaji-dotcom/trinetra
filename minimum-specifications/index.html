Why the scan size matters

Segment uses 3D Slicer, whose memory guidance is roughly ten times the loaded data size. Trinetra also needs memory for surfaces, history and open modules. A compressed download's size is not its memory requirement.

Memory planning is based on 3D Slicer's published requirements, with extra practical allowance for Trinetra. The tiers and storage allowance above are planning estimates, not hardware validation.
